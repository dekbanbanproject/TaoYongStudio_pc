คู่มือเชื่อมบัญชีโพสต์ (ทำครั้งเดียว)

ทุกแพลตฟอร์มใช้ช่องทางทางการ (API) ของแพลตฟอร์มเอง รหัสและ token เก็บไว้ในโฟลเดอร์ secrets บนเครื่องคุณเท่านั้น ห้ามส่งโฟลเดอร์ secrets หรือรหัสเหล่านี้ให้ใคร รวมถึงในแชตกับ Claude

แพลตฟอร์ม โพสต์ได้แบบไหน
YouTube อัตโนมัติเต็มรูปแบบ
Facebook Page อัตโนมัติเต็มรูปแบบ (เป็น Reels)
TikTok ส่งเข้า "แบบร่าง" ในแอป แล้วคุณกดโพสต์เอง (กฎของ TikTok)
Facebook ส่วนตัว โพสต์เองเท่านั้น (Facebook ปิดช่องทางนี้แล้ว)

1. YouTube (ประมาณ 15 นาที)

  1. เข้า https://console.cloud.google.com ล็อกอินด้วยบัญชี Google ที่เป็นเจ้าของช่อง
  2. มุมบนซ้ายกดเลือกโปรเจกต์ → New Project ตั้งชื่อ TaoYongStudio → Create
  3. ช่องค้นหาด้านบนพิมพ์ YouTube Data API v3 → กด Enable
  4. เมนูซ้าย Google Auth Platform (หรือ APIs & Services → OAuth consent screen) → Get started
  5. App name: TaoYongStudio • User support email: อีเมลคุณ • Audience: External • ใส่อีเมลติดต่อ → Create
  6. ไปที่ Audience → Test users → Add users → ใส่อีเมล Google ของคุณเอง
  7. เมนู Clients → Create client → Application type: Desktop app → Create
  8. กด Download JSON จะได้ไฟล์ client_secret_....json
  9. ใน TaoYongStudio แท็บ โพสต์ → YouTube → กด 1. เลือกไฟล์ client_secret.json → เลือกไฟล์ที่ดาวน์โหลด
  10. กด 2. เชื่อมบัญชี YouTube → เบราว์เซอร์จะเปิด → เลือกบัญชี → ถ้าขึ้น "Google hasn't verified this app" ให้กด Continue (เพราะเป็นแอปของคุณเอง) → อนุญาตทุกข้อ → ขึ้น "เชื่อม YouTube สำเร็จ"
  11. ติ๊ก ใช้งาน แล้วกด บันทึกการตั้งค่าโพสต์

หมายเหตุ - ตอนแอปอยู่ในสถานะ Testing Google จะให้ล็อกอินใหม่ทุก ~7 วัน ถ้าไม่อยากล็อกอินบ่อย ไปที่ Audience → Publish app - YouTube ให้อัปโหลดผ่าน API ได้จำกัดต่อวัน วันละ 2-3 คลิปไม่มีปัญหา - ระบบตั้ง "สร้างมาเพื่อเด็ก" และ "มีเนื้อหาสังเคราะห์ (AI)" ให้ทุกคลิปอัตโนมัติ

2. Facebook Page (ประมาณ 15 นาที)

ต้องเป็นผู้ดูแลเพจ (Admin หรือมีสิทธิ์สร้างโพสต์)

  1. เข้า https://developers.facebook.com → My Apps → Create App
  2. Use case: เลือก Manage everything on your Page (หรือ Other → Business) → ตั้งชื่อ TaoYongStudio → Create
  3. ในหน้าแอป ไปที่ App settings → Basic คัดลอก App ID และ App Secret (กด Show)
  4. เปิด Graph API Explorer (ปุ่มในโปรแกรม หรือ https://developers.facebook.com/tools/explorer/)
  5. ช่อง Meta App: เลือก TaoYongStudio
  6. ช่อง User or Page: User Token
  7. Permissions: เพิ่ม pages_show_list, pages_read_engagement, pages_manage_posts
  8. กด Generate Access Token → อนุญาต → เลือกเพจที่จะให้โพสต์ → คัดลอก token ยาวๆ ที่ได้
  9. ใน TaoYongStudio แท็บ โพสต์ → Facebook Page → ใส่ App ID, App Secret, User token
  10. กด ดึงรายชื่อเพจ → เลือกเพจ → กด ใช้เพจนี้ (ได้ token ของเพจแบบไม่หมดอายุ)
  11. ติ๊ก ใช้งาน แล้วกด บันทึกการตั้งค่าโพสต์

หมายเหตุ: แอปอยู่ในโหมด Development ก็โพสต์ลงเพจที่คุณเป็นผู้ดูแลได้ ไม่ต้องส่งตรวจ คลิปต้องยาว 3-90 วินาที (คลิปของ TaoYongStudio อยู่ในช่วงนี้)

3. TikTok (ส่งเข้าแบบร่าง)

  1. เข้า https://developers.tiktok.com → ล็อกอิน → Manage apps → Connect an app
  2. ใส่ชื่อแอป ไอคอน หมวด แล้วในส่วน Platform เลือก Desktop
  3. Add products: เพิ่ม Login Kit และ Content Posting API
  4. ใน Login Kit ตั้ง Redirect URI เป็น http://127.0.0.1:3455/callback/ (ในโปรแกรมมีปุ่ม คัดลอก Redirect URI)
  5. Scopes ที่ต้องใช้: user.info.basic, video.upload
  6. ส่งแอปให้ TikTok ตรวจ (Submit for review) ระหว่างรออาจใช้ได้เฉพาะบัญชีที่เพิ่มเป็น Sandbox/Target user
  7. คัดลอก Client key และ Client secret ใส่ในแท็บ โพสต์ → TikTok → กด เชื่อมบัญชี TikTok
  8. ติ๊ก ใช้งาน แล้วกด บันทึกการตั้งค่าโพสต์

ทุกครั้งที่ระบบส่งคลิป: เปิดแอป TikTok → กล่องข้อความ (Inbox) → กดแจ้งเตือน → วางข้อความโพสต์ (กดปุ่ม "คัดลอกชื่อเรื่อง + คำอธิบาย + แฮชแท็ก" ในหน้าคลิปก่อน) → ตั้งค่า "เนื้อหาที่สร้างด้วย AI" → โพสต์

4. Facebook ส่วนตัว

Facebook ไม่เปิดให้โปรแกรมโพสต์ลงโปรไฟล์ส่วนตัวตั้งแต่ปี 2018 และการใช้บอทคลิกแทนผิดกฎของ Meta อาจทำให้บัญชีถูกระงับ ทางที่แนะนำ: - ให้ระบบโพสต์ลงเพจ แล้วกด แชร์ จากโพสต์ของเพจไปที่โปรไฟล์ หรือ - หน้า คลิป → ปุ่ม Facebook ส่วนตัว → โปรแกรมคัดลอกข้อความและเปิด Facebook กับโฟลเดอร์คลิปให้ คุณลากไฟล์แล้วโพสต์เอง

เลือกโหมดการโพสต์ (แท็บ "โพสต์")

  • ไม่ออโต้: ไม่มีอะไรโพสต์เอง กดปุ่ม YouTube / FB Page / TikTok ในหน้า "คลิป" ทีละคลิป
  • ออโต้ เฉพาะคลิปที่อนุมัติ (แนะนำ): ดูคลิปแล้วกด "อนุมัติ" ระบบจะโพสต์ให้ตามเวลาโพสต์
  • ออโต้ทั้งหมด: ทุกคลิปที่ไม่มีคำเตือนจะถูกโพสต์ตามเวลา โดยไม่ต้องกดอนุมัติ

ทุกโหมด: ไม่โพสต์คลิปซ้ำ, ข้ามคลิปที่มีคำเตือน, ข้ามคลิปที่กด "ไม่ใช้", ไม่เกินจำนวนต่อวันที่ตั้งไว้

คำแนะนำ: ช่องใหม่ควรเริ่มที่วันละ 2 คลิปต่อแพลตฟอร์ม และใช้โหมด "เฉพาะคลิปที่อนุมัติ" เพราะ YouTube และแพลตฟอร์มอื่นตรวจจับช่องที่โพสต์คลิปคล้ายๆ กันจำนวนมาก และอาจปิดการสร้างรายได้

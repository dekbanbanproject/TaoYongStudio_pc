# TaoYongStudio - โปรแกรมสร้างคลิปการ์ตูนเด็กในเครื่อง (Windows 11)

สร้างคลิปการ์ตูนแอนิเมชันภาษาไทยจากไฟล์บท ได้ทั้งแนวตั้ง (TikTok / Shorts) และแนวนอน (YouTube)
พร้อมเสียงพากย์ ลิปซิงก์ ซับไทย เพลงประกอบ เสียงเอฟเฟกต์ ภาพปก และข้อความสำหรับโพสต์
ระบบสร้างคลิปจากบทเดิมวาดและสร้างในเครื่อง ไม่มีค่าใช้จ่ายต่อคลิป ส่วนตัวเลือก Google เป็นบริการแยกต่างหาก

## ติดตั้ง (ครั้งเดียว)

### วิธีที่ 1: ติดตั้งผ่านตัวติดตั้งอัตโนมัติ (แนะนำ)
1. ดับเบิลคลิกไฟล์ **`TaoYongStudio_Setup.exe`**
2. เลือกโฟลเดอร์ปลายทาง (ค่าเริ่มต้นแนะนำคือ `C:\TaoYongStudio`)
3. กด **"เริ่มติดตั้ง"** — ตัวติดตั้งจะแตกไฟล์ ตั้งค่าโฟลเดอร์ เตรียม Python environment (.venv) และสร้างทางลัดบนหน้าเดสก์ท็อปให้อัตโนมัติในคลิกเดียว

### วิธีที่ 2: ติดตั้งด้วยตัวเองผ่าน setup.bat
1. แตกไฟล์ zip ไว้ที่ เช่น `C:\TaoYongStudio` (ไม่ควรวางใน OneDrive)
2. ดับเบิลคลิก `setup.bat` ถ้ายังไม่มี Python โปรแกรมจะติดตั้งให้ แล้วให้เปิด `setup.bat` อีกรอบ
3. รอจนขึ้นคำว่า `READY`
4. ดับเบิลคลิก `render_samples.bat` เพื่อสร้างคลิปตัวอย่าง 2 เรื่อง แล้วดูผลในโฟลเดอร์ `output`

### การคอมไพล์ไฟล์ติดตั้งใหม่ (สำหรับนักพัฒนา)
หากต้องการสร้างหรืออัปเดตไฟล์ `TaoYongStudio_Setup.exe` ใหม่หลังจากแก้ไขโค้ด:
- ดับเบิลคลิก **`build_installer.bat`**
- ระบบจะแพ็กไฟล์โปรแกรมทั้งหมดและคอมไพล์เป็น `TaoYongStudio_Setup.exe` ใหม่อัตโนมัติ

## ใช้งานประจำวัน

1. วางไฟล์บท `.json` ไว้ใน `scripts\inbox\` (พนักงาน AI ฝ่ายเขียนบททำให้ ดูรูปแบบใน `SCRIPT_FORMAT.md`)
2. ดับเบิลคลิก `run_batch.bat` (หรือฝ่ายผลิตสั่ง `studio.bat batch`)
3. ผลลัพธ์อยู่ใน `output\วันที่\ชื่อคลิป\`
   - `..._vertical.mp4` สำหรับ TikTok / YouTube Shorts
   - `..._horizontal.mp4` สำหรับ YouTube แบบปกติ
   - `thumb_*.jpg` ภาพปก, `subtitles.srt` ซับ, `upload.txt` ชื่อเรื่อง คำอธิบาย แฮชแท็ก
   - `meta.json` สถานะ และรายการที่ต้องตรวจ (`needs_review`)
4. บทที่สร้างเสร็จจะถูกย้ายไป `scripts\done\` บทที่ผิดพลาดไป `scripts\failed\` พร้อมไฟล์บอกสาเหตุ

## วางแผนและเลือก AI เขียนบท

ในแท็บ **วางแผน** เลือกไอเดียหรือพิมพ์หัวข้อ เลือก **Claude Pro / Gemini Pro / ChatGPT Plus** และเลือก **ตอนนี้ / กำหนดวันเวลา** ก่อนกด **ส่งคำขอ**

- **Claude Pro และ ChatGPT Plus:** โปรแกรมคัดลอกคำสั่งและเปิดหน้าแชต ให้วางคำสั่งแล้วส่งในแชต หากกำหนดเวลา AI จะเสนอให้ตั้งงานตามเวลานั้น ต้องยืนยันงานในแชตของบริการก่อน งานที่เสร็จแล้วให้คัดลอก JSON กลับมากด **นำเข้าบทจาก AI** ในโปรแกรม
- **Gemini Pro:** ถ้าบันทึก Gemini API key ไว้ในแท็บ **ตั้งค่า** โปรแกรมเขียนบททันทีหรือใช้ Windows Task Scheduler ทำตามวันที่และเวลาที่เลือก ผลลัพธ์เข้าคลังบทอัตโนมัติ โควตาและค่าใช้จ่ายของ API แยกจากการสมัคร Gemini Pro; ถ้าไม่มี key โปรแกรมจะเปิด Gemini ในเว็บเหมือนตัวเลือกแชตข้างต้น
- งานที่ตั้งเวลาใน Windows จะรันเมื่อบัญชี Windows พร้อมใช้งาน และต้องใช้ API key ที่บันทึกไว้ในเครื่อง หากงานไม่สำเร็จ สถานะจะแสดงข้อผิดพลาดในตารางคำขอ

สถานะ **รอ Claude อ่านคำขอ (คิวเดิม)** ใช้กับคำขอเก่าที่สร้างก่อนมีตัวเลือก AI ใหม่ โดยโปรแกรมไม่ได้ส่งงานให้ Claude โดยตรง

ความเร็วโดยประมาณ: คลิปยาว 35 วินาที ทั้งสองแบบ ใช้เวลาราว 1 นาที วันละ 10 คลิปใช้ราว 10-15 นาที

## คำสั่งทั้งหมด (`studio.bat ...`)

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `studio.bat check` | ตรวจว่าเครื่องพร้อม และเสียงพากย์แบบไหนใช้ได้ |
| `studio.bat validate ไฟล์.json` | ตรวจบทโดยไม่สร้างคลิป |
| `studio.bat render ไฟล์.json --format both` | สร้างคลิปเดียว |
| `studio.bat batch --limit 10` | สร้างทุกบทใน inbox (จำกัดจำนวนได้) |
| `studio.bat still ไฟล์.json --at 5` | บันทึกภาพนิ่งหนึ่งเฟรมไว้ดูเร็วๆ |
| `studio.bat voices` | ดูรายชื่อเสียงไทยที่มี |
| `studio.bat import-video ไฟล์.mp4 --platform youtube --title "ชื่อเรื่อง" --format vertical` | แปลงไฟล์วิดีโอเข้าคลังคลิป |
| `studio.bat google-video --platform youtube --title "ชื่อเรื่อง" --prompt "ฉากที่ต้องการ"` | สร้างวิดีโอด้วย Gemini Omni Flash API ที่เปิดชำระเงิน (`GEMINI_API_KEY`) |
| `studio.bat caption-video --folder โฟลเดอร์คลิป --platform youtube` | ให้ Gemini เขียนชื่อเรื่อง คำอธิบาย และแฮชแท็กจากภาพในคลิป (`GEMINI_API_KEY`) |

## หน้าสร้างและโพสต์

เปิดแท็บ **สร้างและโพสต์** แล้วเลือกปุ่มใหญ่เต็มแถว TikTok, YouTube, Shopee, Facebook Profile หรือ Facebook Page โปรแกรมแสดงหน้าแพลตฟอร์มที่เลือกเต็มพื้นที่ แต่ละหน้ามีแหล่งวิดีโอ 4 แบบ:

1. **สร้างในเครื่อง** เลือกบทจาก `scripts\inbox\` หรือ `scripts\done\` แล้วกดสร้าง
2. **คลิป/ไฟล์ที่มี** เลือกคลิปในคลัง หรือเลือกไฟล์จากเครื่อง โปรแกรมแปลงเป็น MP4 และให้ Gemini เขียนข้อความโพสต์จากภาพในคลิปโดยอัตโนมัติเมื่อมี API key
3. **Google Flow (เครดิตบัญชี)** ในแท็บ **บท** เลือกเรื่องแล้วกด **สร้างแอนิเมชันด้วย Google Flow** โปรแกรมเลือกแพลตฟอร์มและแนวภาพให้ คัดลอกพรอมต์ และเปิดเว็บ Flow จากหน้า **สร้างและโพสต์** เลือกพรอมต์ทั้งเรื่องสำหรับ Flow Agent หรือเลือกแยกฉากได้ สร้างและดาวน์โหลดใน Flow แล้วกด **นำเข้าคลิปที่ดาวน์โหลด** เพื่อให้คลิปเข้าคลังพร้อมชื่อเรื่อง คำอธิบาย และแฮชแท็กจากบท Flow ใช้เครดิตของบัญชี Google แยกจาก Gemini API key และคลิปหนึ่งชุดอาจต้องสร้างหลายช็อตแล้วรวมใน Scenebuilder
4. **Google API เสียเงิน** โปรแกรมเตรียมพรอมต์จากบทให้ เลือกความละเอียดแล้วกดสร้าง โปรแกรมใช้ Gemini Omni Flash API และนำคลิปเข้าคลังอัตโนมัติ

ในช่องพรอมต์ของ Google Flow, Google API และ Facebook Profile กด **AI วิเคราะห์พรอมต์** เพื่อให้ Gemini ตรวจความชัดเจนของเนื้อหา จังหวะเวลา ภาพ และเสียง โปรแกรมจะแสดงข้อเสนอแนะพร้อมพรอมต์ที่ปรับปรุงให้ตรวจและแก้ไขก่อนกด **ใช้พรอมต์นี้** ต้องตั้ง Gemini API key ในแท็บตั้งค่าก่อน และการวิเคราะห์ใช้โควตา API ตามบัญชีของคุณ

ชื่อเรื่อง คำอธิบาย และแฮชแท็กจากบทที่พนักงาน AI เขียนจะแสดงเป็นตัวอย่างอ่านอย่างเดียว ไม่ต้องกรอกเอง สำหรับคลิปที่นำเข้าจากเครื่อง ให้ใส่ Gemini API key ครั้งเดียวในแท็บ **ตั้งค่า** โปรแกรมเข้ารหัสคีย์ไว้สำหรับบัญชี Windows นี้ หากนำเข้าก่อนตั้งคีย์ ให้เลือกคลิปแล้วกด **AI เขียนข้อความโพสต์** คีย์นี้อาจใช้โควตาฟรีหรือมีค่าใช้จ่ายตามบัญชี Google ของคุณ

เปิดดูคลิปแล้วกดปุ่มโพสต์ได้เลย โปรแกรมจะถามยืนยันการตรวจและอนุมัติในขั้นตอนเดียว คลิปที่นำเข้าหรือสร้างด้วย Google ยังควรตรวจภาพ เสียง และข้อความก่อนเผยแพร่
แท็บ YouTube เลือกแนวตั้งหรือแนวนอนได้ ส่วนแพลตฟอร์มอื่นตั้งเป็นแนวตั้ง

- YouTube และ Facebook Page โพสต์ผ่านบัญชี/API ที่เชื่อมในแท็บ **ตั้งค่าโพสต์**
- TikTok ส่งคลิปเข้าแบบร่างแล้วเจ้าของบัญชีกดโพสต์ในแอป
- Facebook Profile และ Shopee เปิดไฟล์กับเว็บไซต์ พร้อมคัดลอกข้อความให้โพสต์เอง
- Google Flow: https://flow.google.com/ และคู่มือโควตา https://support.google.com/flow/answer/16526234
- Gemini API สำหรับเขียนข้อความ: https://ai.google.dev/gemini-api/docs/pricing
- Gemini Omni Flash API: https://ai.google.dev/gemini-api/docs/omni และราคาปัจจุบัน https://ai.google.dev/gemini-api/docs/pricing

## เสียงพากย์ (สำคัญ อ่านก่อนเปิดสร้างรายได้)

โปรแกรมลองตามลำดับใน `config.json` → `tts.engines`

- `azure` เสียง Microsoft แบบทางการ ใช้เชิงพาณิชย์ได้ ต้องสมัคร Azure Speech แล้วใส่คีย์ใน `tts.azure_key`
  แพ็กเกจฟรีได้ 500,000 ตัวอักษรต่อเดือน พอสำหรับวันละ 10 คลิป
- `edge` เสียงเดียวกัน ฟรี ผ่านบริการอ่านออกเสียงของ Microsoft Edge ต้องต่ออินเทอร์เน็ต
  **เหมาะกับช่วงทดสอบ** เพราะไม่ใช่ช่องทางที่ Microsoft อนุญาตสำหรับงานเชิงพาณิชย์โดยตรง
- `sapi` เสียงไทยของ Windows ใช้ได้ออฟไลน์ ติดตั้งที่ Settings → Time & language → Speech → Add voices → Thai
- `espeak` เสียงหุ่นยนต์ ใช้ทดสอบเท่านั้น

ถ้าคลิปใดใช้เสียงสำรอง `meta.json` จะมีคำเตือนใน `needs_review` ฝ่ายตรวจจะไม่ส่งคลิปนั้นไปโพสต์

## เพลง

ค่าเริ่มต้นสร้างเพลงใหม่ทุกคลิป ปลอดลิขสิทธิ์ ถ้าอยากใช้เพลงของตัวเอง (ที่มีสิทธิ์ใช้)
ให้ใส่ไฟล์ไว้ในโฟลเดอร์ เช่น `music\` แล้วแก้ `config.json` → `"audio": {"music": "music"}`

## ตั้งค่าอื่นใน config.json

- `channel_name` ชื่อช่อง แสดงเล็กๆ มุมซ้ายบน
- `outro_text` ข้อความปิดท้ายคลิป
- `voices` เปลี่ยนเสียงหรือระดับเสียงของแต่ละตัวละคร
- `video.formats` เลือกสร้างเฉพาะแนวตั้ง หรือทั้งสองแบบ
